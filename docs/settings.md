# Settings for QubeVM Emulator

## Settings

Many of the options you have used on the main screen are now moved under
settings with new versions of QubeVM. Under settings you can find some of
these options:

### Qube Graphics Engine

**VM Refresh Rate**
Virtual Machine display refresh rate, Higher values are smoother but use more resources.

**Pointer Speed**
Cursor movement speed in trackpad/relative mode.

**Fullscreen**
Show Fullscreen.

**Mouse Button Click Delay**
Delay between mouse button clicks. Lower values have better performance but mouse events might be not be understood by the emulator so use higher values.

### Updates

**Check for Software Updates**
Check for software updates on startup.

### Files

**Clear Directory History**
Remove all remembered file paths from storages, removable storages.

### Screen

**Orientation**
The orientation that the virtual machine will be displayed. You can lock the orientation if you frequently move your Android device. Keep in mind this is not the orientation for the main screen which will always be auto rotated.

**Always Toolbar**
It is helpful sometimes to always show the toolbar if you use it a lot especially if you are on desktop mode and you can spare some extra pixels.

### QMP

**Enable QMP Server**
QMP Server is QEMU's communication means that allows you to do many things like pause and restore the virtual machine state, change the vnc password, and change CD ROM and Floppy disks. Run QMP Server. This is needed to changing removable drives.

**Allow External QMP Connections**
If you want to connect to the QMP server from your desktop. Allow external QMP Clients. Needs app restart. Connections are not encrypted so only use in a private network that you trust!

### VNC

**Allow External VNC Connections**
You can allow a computer on the same network to connect to the VNC service. The communication is not encrypted so make sure you trust the network you are using! Allow external VNC Clients. Needs app restart. VNC Connections are not encrypted so only use in a private network that you trust!

### Virtual Keys

**Customize Virtual Keys**
Add, remove or reorder virtual keys.

**Row count**
Number of rows used to arrange virtual keys.

**Show all keys by default**
Adds F1-F12, Insert and Delete to the default layout.

**Open with keyboard**
Show virtual keys automatically when the soft keyboard opens.

**Single tap for Super key**
Send Super key on a single tap instead of toggling it.

### Disk

**Disk Cache**
If you encounter issues set to Default.
